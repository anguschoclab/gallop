## 2026-06-12 - Adding explicit button types to custom controls\n**Learning:** When using raw HTML `<button>` tags (e.g., for custom filter toggle selectors), omitting `type="button"` can cause unintended form submission behaviors if these components are ever placed inside a form. Additionally, adding `aria-pressed` provides vital state information for screen readers when buttons are used as toggles.\n**Action:** Always include `type="button"` and relevant ARIA state attributes (like `aria-pressed`) when creating or modifying custom button elements.
