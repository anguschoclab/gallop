## 2024-10-28 - Standardized Empty States
**Learning:** Inconsistent ad-hoc empty states can create fragmented user experiences; using a standard `EmptyState` component with an icon and clear description unifies the UI and makes empty screens more engaging and accessible.
**Action:** Always scan for ad-hoc empty states (e.g. `No X available`) and replace them with the standardized `<EmptyState>` component from `@/shared/ui/common/EmptyState`.
