## 2024-09-14 - Optimize O(N²) Object.fromEntries allocation in sire analytics
**Learning:** Sire analytics metrics (`calculateCi`, `classifySire`) iterate over all active stallions and continuously rebuilt the same `horsesDict` dictionary dynamically inside tight loops using `Object.fromEntries(allHorses.map(...))`. This creates a devastating O(S² * H) time complexity and massive garbage collection pauses when computing breeding leaderboards.
**Action:** Utility functions that require map lookups derived from arrays passed inside loops should accept an optional pre-computed dictionary (`horsesDict?: Record<string, Horse>`) rather than rebuilding the map on every call. The dictionary creation was hoisted outside the loop and passed down, reducing time complexity and allocation overhead.
