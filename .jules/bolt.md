## 2024-06-03 - Array Iteration vs Object Keys for Hot Loops
**Learning:** In highly frequent hot paths like per-tick updates (`recordTick`), using `for..of` over arrays vs manually unrolled loops vs standard `for` loops. While manually unrolling loops using static property access is technically the fastest, it severely damages maintainability (if a new `FactorKey` is added, it will be silently missed if the unrolled list isn't updated). A standard indexed `for (let i = 0; i < arr.length; i++)` loop offers a great middle ground, running much faster than `for..of` while maintaining generic safety. Additionally, standard Math methods (`Math.min`, `Math.max`, `Math.abs`) incur significant overhead in these hot loops and should be replaced with inline conditionals.
**Action:** Minimize overhead by avoiding `for..of` and substituting Math methods with manual inline conditionals, but prefer an indexed `for` loop over manually unrolling for better maintainability if iterating over known arrays.
