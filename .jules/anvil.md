## 2024-06-25 - Strengthened AI Npc Manager Stable States
**Learning:** React component `RivalIntelTab.tsx` was loosely typing `stableStates` as `Record<string, any>`, which bypassed type safety when accessing properties like `strategicDirectives` or `worldAssessment`. This resulted in potential runtime errors (e.g. `d.recommendedActions.length` being undefined) because the type system didn't enforce correct structure handling for the loosely typed object.
**Action:** Replaced `Record<string, any>` with `Record<string, StableAIState>` to properly reflect the core NPC AI state type. Fixed the subsequently surfaced type errors in the component by handling potentially undefined properties (`recommendedActions`, `topThreats`, `strategicDirectives`), and aligning property names with their strict interface definitions (`playerStrength` -> `playerDominance`, `action` -> `type`).
