# Player-Facing Syndication with Investor Management — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the syndication system player-facing. Currently syndicates exist as a data structure but players cannot solicit investors, manage expectations, or see investor reactions to race outcomes. This plan adds investor profiles with personality-driven expectations, a 3-step SolicitationWizard, day-advance pipeline hooks for expectation checking, reputation deltas on outcome met/missed, and a full `/syndicate/$syndicateId` route with tabs for Overview, Investors, and Financials.

**Architecture:** New `InvestorRecord` and `InvestorExpectation` types live on `Syndicate`. An `InvestorBidIntent` / `InvestorExpectationCheckIntent` pair threads through the Intent → Impact → Handler pipeline. NPC investor bids are generated by a personality system (`conservative`, `aggressive`, `speculator`). The `solicitInvestors` and `handleInvestorExpectationCheck` store actions are added to `syndicateSlice.ts`. The `investorExpectationPhase` at order 62 runs after race results and before retirement to check expectations.

**Tech Stack:** TypeScript, Zustand, TanStack Router, React 19; no new libraries.

---

## Context

The current `Syndicate` type has `shares`, `ownershipPct`, `revenue`, and `expenses` — but no investor list and no mechanism for the player to bring in co-owners. Syndicates are effectively solo operations. In genre comparators (Stud Farm Simulator, Howse Racing Manager), syndicates are a major mid-game lever: raise capital, manage NPC investor pressure, and navigate the tension between short-term results and long-term breeding strategy.

The existing reputation system (0–1000 scale, 7 tiers: `unknown → legendary`) is already implemented and will be used as the stake-in-ground for investor attraction and expectation outcomes.

**Key constraints:**
- Player must retain ≥ 51% (`SYNDICATE_MIN_PLAYER_OWNERSHIP_PCT = 0.51`)
- Investors have personalities that determine what they expect: `conservative` investors expect minimal dividend + stable ROI, `aggressive` investors expect prize money, `speculator` investors expect asset appreciation
- Missing expectations triggers a reputation hit; exceeding them gives a reputation bonus
- The SolicitationWizard is a 3-step dialog: (1) pick syndicate, (2) configure ask, (3) review terms

## Conventions (read before starting)

- The player's ownership share in a syndicate should never fall below 51%. The `solicitInvestors` action must validate this.
- Investors are NPCs — they are not in `stables` or `horses` tables. They live only in `syndicate.investors`.
- `InvestorPersonality` determines both what they bid (how much per share) and what they expect (quarterly prize money, dividend, or horse valuation gain).
- Expectation periods are 30 days (one "season"). The `investorExpectationPhase` runs on multiples of 30 past the syndicate formation day.
- Reputation impacts: miss expectation = -5 reputation per investor per period; meet = no change; exceed = +3 reputation per investor per period.
- The SolicitationWizard dialog uses the existing modal system (if one exists) or a simple `<dialog>` element — do not add a new modal library.
- TanStack Router: new route file `src/routes/syndicate.$syndicateId.tsx` creates `/syndicate/$syndicateId`. Tabs are rendered via local state, not sub-routes.
- Test convention: `src/tests/core/<module>/<filename>.test.ts`.

```typescript
export function generateInvestor(
  personality: InvestorPersonality,
  sharesPct: number,
  capitalPerPct: number,
  joinedDay: number,
  seed: string,
): InvestorRecord {
  const NAMES_BY_PERSONALITY: Record<InvestorPersonality, string[]> = {
    conservative: ["Reginald Hartley", "Margaret Fenn", "Victor Solano", "Helen Chu"],
    aggressive:   ["Brent Carver", "Talia Sharp", "Mick Bauer", "Jasmine Webb"],
    speculator:   ["Dallas O'Brien", "Krys Endo", "Fabian Marsh", "Priya Lal"],
  };
  const namePool = NAMES_BY_PERSONALITY[personality];
  const nameIndex = Math.abs(seed.charCodeAt(0) + seed.charCodeAt(1)) % namePool.length;

  const METRIC_BY_PERSONALITY: Record<InvestorPersonality, ExpectationMetric> = {
    conservative: "dividend",
    aggressive:   "prize_money",
    speculator:   "asset_appreciation",
  };

  const TARGET_MULTIPLIER: Record<InvestorPersonality, number> = {
    conservative: 0.06, // 6% return per period on capital
    aggressive:   0.12, // 12% in prize money share
    speculator:   0.15, // 15% asset appreciation
  };

  const capital = sharesPct * capitalPerPct;
  const targetAmount = capital * TARGET_MULTIPLIER[personality];

  return {
    id: `investor-${seed}`,
    name: namePool[nameIndex],
    personality,
    sharesPct,
    capitalContributed: capital,
    joinedDay,
    expectation: {
      metric: METRIC_BY_PERSONALITY[personality],
      targetAmount,
      periodDays: INVESTOR_EXPECTATION_PERIOD_DAYS,
      lastCheckedDay: joinedDay,
    },
    status: "active",
    satisfactionScore: INVESTOR_SATISFACTION_INITIAL,
  };
}
```

```typescript
export type ExpectationOutcome = "exceeded" | "met" | "missed";

export interface PeriodResult {
  prizeMoney: number;
  dividend: number;
  assetGain: number;
}

export interface ExpectationCheckResult {
  outcome: ExpectationOutcome;
  reputationDelta: number;
  satisfactionDelta: number;
}

export function checkExpectation(
  investor: InvestorRecord,
  result: PeriodResult,
): ExpectationCheckResult {
  const METRIC_VALUE: Record<ExpectationMetric, number> = {
    prize_money:        result.prizeMoney * investor.sharesPct,
    dividend:           result.dividend * investor.sharesPct,
    asset_appreciation: result.assetGain * investor.sharesPct,
  };

  const actual = METRIC_VALUE[investor.expectation.metric];
  const target = investor.expectation.targetAmount;

  if (actual >= target * 1.2) {
    return { outcome: "exceeded", reputationDelta: INVESTOR_REPUTATION_GAIN_EXCEED, satisfactionDelta: 10 };
  } else if (actual >= target) {
    return { outcome: "met", reputationDelta: 0, satisfactionDelta: 2 };
  } else {
    return { outcome: "missed", reputationDelta: -INVESTOR_REPUTATION_HIT_MISS, satisfactionDelta: -15 };
  }
}
```

## Task 4: Investor expectation pipeline phase

**Files:**

- Modify: `src/core/time/pipeline.ts`

- [ ] **Step 1: Implement the phase**

The phase fires on every day that is a multiple of `INVESTOR_EXPECTATION_PERIOD_DAYS` past each syndicate's formation day. It emits intents — does not mutate state directly.

```typescript
export function investorExpectationPhase(state: GameState): InvestorExpectationCheckIntent[] {
  const intents: InvestorExpectationCheckIntent[] = [];

  for (const syndicate of state.playerSyndicates ?? []) {
    for (const investor of syndicate.investors ?? []) {
      if (investor.status !== "active") continue;

      const daysSinceLastCheck = state.day - investor.expectation.lastCheckedDay;
      if (daysSinceLastCheck < investor.expectation.periodDays) continue;

      intents.push({
        type: "InvestorExpectationCheck",
        syndicateId: syndicate.id,
        investorId: investor.id,
        day: state.day,
      });
    }
  }

  return intents;
}
```

```typescript
solicitInvestors: (syndicateId: string, slots: Array<{ personality: InvestorPersonality; sharesPct: number }>) => {
  set((s) => {
    const idx = (s.playerSyndicates ?? []).findIndex((syn) => syn.id === syndicateId);
    if (idx === -1) return s;

    const syndicate = s.playerSyndicates![idx];
    const existingInvestorShares = syndicate.investors.reduce((sum, i) => sum + i.sharesPct, 0);
    const newShares = slots.reduce((sum, slot) => sum + slot.sharesPct, 0);
    const totalAfter = existingInvestorShares + newShares;

    if (1 - totalAfter < SYNDICATE_MIN_PLAYER_OWNERSHIP_PCT) {
      return s; // guard: player must retain >= 51%
    }

    if (syndicate.investors.length + slots.length > SYNDICATE_MAX_INVESTORS) {
      return s; // guard: max investor count
    }

    const newInvestors = slots.map((slot, i) =>
      generateInvestor(
        slot.personality,
        slot.sharesPct,
        syndicate.totalShares * 1000, // $1000 per share point as base valuation
        s.day,
        `${syndicateId}-${s.day}-${i}`,
      )
    );

    const updatedSyndicates = [...(s.playerSyndicates ?? [])];
    updatedSyndicates[idx] = {
      ...syndicate,
      investors: [...syndicate.investors, ...newInvestors],
      playerSharesPct: 1 - (existingInvestorShares + newShares),
    };

    return { playerSyndicates: updatedSyndicates };
  });
},
```

The wizard is a controlled component with local `step: 1 | 2 | 3` state. On step 3 confirm, it calls `solicitInvestors` and closes.

```tsx
export function SolicitationWizard({ open, onClose }: { open: boolean; onClose: () => void }) {
  const [step, setStep] = useState<1 | 2 | 3>(1);
  const [syndicateId, setSyndicateId] = useState<string>("");
  const [slots, setSlots] = useState<Array<{ personality: InvestorPersonality; sharesPct: number }>>([
    { personality: "conservative", sharesPct: 0.1 },
  ]);
  const solicitInvestors = useRacingStore((s) => s.solicitInvestors);
  const syndicates = useRacingStore((s) => s.playerSyndicates ?? []);

  if (!open) return null;

  return (
    <dialog open className="solicitation-wizard">
      <h2>Solicit Investors — Step {step} of 3</h2>
      {step === 1 && <StepSelectSyndicate syndicates={syndicates} value={syndicateId} onChange={setSyndicateId} onNext={() => setStep(2)} />}
      {step === 2 && <StepConfigureAsk slots={slots} onChange={setSlots} onBack={() => setStep(1)} onNext={() => setStep(3)} />}
      {step === 3 && (
        <StepReviewTerms
          slots={slots}
          onBack={() => setStep(2)}
          onConfirm={() => { solicitInvestors(syndicateId, slots); onClose(); }}
        />
      )}
      <button onClick={onClose} className="btn-ghost">Cancel</button>
    </dialog>
  );
}
```
