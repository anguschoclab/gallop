## 2025-02-19 - React.memo() on frequently updated Leaderboard
**Learning:** The live race `Leaderboard` component was not wrapped in `React.memo()`. This component is re-rendered many times per second during a live race, since its parent (`RaceBroadcast`) receives the simulation tick. Although the underlying data passed to `Leaderboard` is correctly memoized and optimized (e.g., via `useLeaderboardState`), omitting `React.memo()` causes React to re-render the entire leaderboard list continuously even when the derived props (like `sorted` and `positionRank`) remain referentially equal between frames (e.g., when positions haven't shuffled).
**Action:** Always wrap presentation components that receive frame-driven props in `React.memo()`, especially large lists like a leaderboard, so they only re-render when the actual derived data changes.
