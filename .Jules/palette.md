## 2026-05-04 - AppShell Navigation and Icon Buttons Accessibility
**Learning:** Adding semantic HTML and ARIA roles significantly improves navigation and actions for screen readers. Using `aria-current='page'` on active links and adding explicit `aria-label` attributes to icon-only buttons creates a more usable interface without changing the visual design.
**Action:** Always add explicit ARIA labels for icon-only action buttons and ensure main navigation correctly flags the active page using `aria-current`.
